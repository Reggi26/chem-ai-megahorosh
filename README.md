# ChemAI: Predict the Cure

ML-проект по предсказанию биологической активности химических соединений против вируса гриппа.

## Описание проекта

Данный проект выполнен в рамках хакатона «ChemAI: Predict the Cure».

### Цель соревнования — предсказать биологическую активность химических соединений против вируса гриппа на основе молекулярных дескрипторов.

Для каждого соединения необходимо предсказать три значения:

- IC50 — концентрация, подавляющая 50% активности вируса;
- CC50 — концентрация токсичности для 50% клеток;
- SI (Selectivity Index) — индекс селективности.

Задача оценивается по **метрике RMSE (Root Mean Squared Error)**, усредненный по трем таргетам:


**score = (RMSE(IC50) + RMSE(CC50) + RMSE(SI)) / 3**

# Используемые данные

В соревновании использовались:

- train.csv — обучающая выборка;
- test.csv — тестовая выборка;
- sample_submission.csv — шаблон submission.

Каждое химическое соединение описывается 214 числовыми молекулярными дескрипторами.

Признаки включают:

- физико-химические свойства;
- электронные и зарядовые характеристики;
- топологические и структурные дескрипторы;
- Поверхностные дескрипторы (VSA);
- функциональные группы;
- Специфические дескрипторы.


# Подход к решению

## Предобработка данных

Для обработки пропущенных значений использовалась медианная импутация.
Также выполнялась базовая подготовка признаков для последующего обучения моделей.


## Отбор признаков

Для отбора наиболее информативных признаков использовались ансамблевые методы на основе деревьев решений.
Это позволило уменьшить влияние шумовых признаков и повысить устойчивость модели.


## Используемые модели

В ходе экспериментов рассматривались несколько моделей машинного обучения:

- CatBoostRegressor
- XGBoostRegressor
- ExtraTreesRegressor
- GradientBoostingRegressor
- RidgeCV

Для каждой целевой переменной (IC50, CC50 и SI) обучались отдельные модели, что позволило учитывать различия в распределениях target-показателей.


## Ансамблирование моделей

Финальные предсказания формировались на основе комбинации нескольких моделей.
Ансамблирование позволило повысить стабильность результатов и улучшить итоговое качество модели.
Для target-переменной SI дополнительно рассматривалась корректировка предсказаний через соотношение IC50 и CC50, что позволило повысить согласованность итоговых результатов.

## Валидация

Для оценки качества использовалась KFold cross-validation.
Также применялись out-of-fold predictions для более стабильной оценки качества модели.
Для воспроизводимости результатов использовался фиксированный random seed.

# Инструкция по воспроизведению результатов

## 1. Клонирование репозитория

```bash
git clone https://github.com/Reggi26/chem-ai-megahorosh.git
cd chem-ai-megahorosh
```


## 2. Установка зависимостей

Перед запуском проекта необходимо установить используемые библиотеки:

```bash
pip install -r requirements.txt
```


## 3. Структура проекта

Файлы датасета должны находиться в папке:

```text
data/
```

Необходимые файлы:

- train.csv
- test.csv
- sample_submission.csv


## 4. Запуск проекта

Для запуска проекта необходимо открыть Jupyter Notebook:

```bash
jupyter notebook
```

После запуска необходимо открыть файл:

```text
notebooks/solution.ipynb
```

И выполнить все ячейки последовательно.


## 5. Генерация submission-файла

После выполнения notebook будет создан итоговый submission-файл.

Файл сохраняется в папке:

```text
submissions/
```

Пример:

```text
submissions/best_271_83.csv
```


## 6. Воспроизводимость результатов

Для обеспечения воспроизводимости:

- используется фиксированный random seed;
- применяется KFold cross-validation;
- используются одинаковые входные данные;
- модели обучаются отдельно для каждого target-показателя.

Это позволяет повторно получить сопоставимые результаты при повторном запуске проекта.
